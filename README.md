rolleybus System Input Device (PXN V10 Pro Fix)

Это форк оригинального модуля ввода для Garry's Mod (GMod), используемого в аддоне Trolleybus System (FS Project).

Цель форка — исправить критический вылет игры (0xc0000409), возникающий при подключении современных рулей (например, PXN V10 Pro), и сохранить полную совместимость с оригинальным Lua API аддона.
❓ Проблема, которую решает этот форк

Оригинальный модуль (2021 года) вызывал вылет игры при попытке считать данные с руля PXN V10 Pro.
Причина: код использовал жесткий лимит MAX_DEVICE_OBJECTS = 64. Современные рули (с педалями, шифтерами и множеством кнопок) отдают больше объектов через DirectInput. Выход за пределы массива вызывал повреждение памяти и вылет движка (0xc0000409).

Что сделано в этом форке:

    Увеличен лимит объектов до 256.

    Внедрена безопасная обработка осей через dwOfs (реальные смещения в DIJOYSTATE2), а не просто перебор по индексам.

    Сохранена полная совместимость с оригинальным Lua API (GetState, GetButtonState, GetAxles и т.д.). Аддон Trolleybus FS будет работать без изменения его скриптов.

🛠️ Как установить готовый DLL

    Скачай готовый gmcl_trolleybus_input_device_win64.dll из раздела Releases (или собери сам, см. ниже).

    Перейди в папку с игрой:
    ...\Steam\steamapps\common\GarrysMod\garrysmod\lua\bin\

    Замени оригинальный gmcl_trolleybus_input_device_win64.dll на скачанный.

    Запусти Garry's Mod (64-bit версию) и проверь руль в меню настроек троллейбуса.

🧑‍💻 Как собрать DLL самостоятельно

    Установи Visual Studio 2022 (с рабочей нагрузкой «Разработка классических приложений на C++»).

    Склонируй репозиторий garrysmod_common (с подмодулями) и sourcesdk-minimal.

    Настрой проект через premake5 (или используй готовый .sln файл).

    В свойствах проекта (Release x64) добавь библиотеки:
    dinput8.lib; dxguid.lib; ole32.lib

    Собери проект. Готовый DLL будет лежать в папке bin/x64/Release/.

    Переименуй его в gmcl_trolleybus_input_device_win64.dll.

🔧 Как добавить поддержку другого руля (например, Moza)

Этот модуль использует DirectInput 8. Если руль Moza (или любой другой) корректно определяется в Windows (в joy.cpl), он должен работать и здесь. Однако, если руль использует нестандартные оси (например, дополнительные слайдеры), может потребоваться правка кода.

Что нужно сделать для добавления нового руля:

    Проверь joy.cpl: Убедись, что руль работает в режиме D-Input и Windows видит все его оси (руль, педали, сцепление).

    Собери отладочную версию: В коде есть функция UpdateState, которая считывает оси. Добавь логирование (запись в файл C:\trolleybus_debug.txt), чтобы увидеть, какие значения приходят от осей.
    Совет: если руль использует нестандартные оси, они могут не попасть в DIJOYSTATE2. В этом случае нужно добавить обработку GUID_Slider или GUID_*Axis в функции DeviceObjectCallback.

    Настрой маппинг в Lua: В оригинальном аддоне Trolleybus FS настройки осей (руль, газ, тормоз) хранятся в конфигурационных файлах. Если руль определяется, но не работает, попробуй переназначить оси в меню настроек троллейбуса (вкладки «Руль», «Педаль пуска», «Педаль тормоза»).

    Создай Pull Request: Если ты добавил поддержку Moza (или другого руля), отправь свои изменения в этот репозиторий, чтобы помочь другим пользователям.
